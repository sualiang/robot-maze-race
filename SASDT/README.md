# SASDT — Super AI Development Team

> **全局规则体系** — 所有项目、所有 Claude Code 开发任务遵循本体系。
>
> 本目录是 SASDT 规则体系的**唯一源**。各项目根目录的 CLAUDE.md 以及 spawn 子 Agent 时的 prompt 均从本目录加载对应内容。
>
> **版本**：V1.0 | **最后更新**：2026-07-25 | **维护人**：项目/产品总监

---

## 使用方式

### 对于我（项目/产品总监）
- 本目录由我维护，所有规则变更在此进行
- spawn 技术总监/开发工程师时，从本目录选取对应规则注入 prompt
- 通过飞书向测试/运维分发所需上下文

### 对于技术总监 / 开发工程师（Claude Code CLI 子 Agent）
- spawn 启动时会自动获得当前项目的 CLAUDE.md + 对应的 SASDT 角色规则
- 当前项目的 Hook 脚本在 Claude Code CLI 启动时自动加载

### 对于测试（豆包 API）、运维（OpenClaw）、审计（千问）
- 我通过飞书指令附带所需规则上下文
- 审计（千问）可直接读取本目录全部内容和各项目代码

## 项目接入流程

新项目加入 SASDT 体系时，在项目根目录创建 `CLAUDE.md`，引用本体系，并创建对应的目录：

```
[项目根目录]/
├── CLAUDE.md         ← 项目上下文 + 引用全局规则
├── MCP/              ← 项目级知识库（概览/架构/决策/故障台账）
├── hooks/            ← 项目级 Hooks 熔断脚本
│   ├── pre-hooks/
│   ├── post-hooks/
│   └── stop-hooks/
└── ...源码
```
